**Project Summary**

This is a basic OTP messaging app built using React. It allows a user to browse a list of contacts, view contact details, and send a randomly generated OTP as a message. Sent messages are tracked in a separate view.

**Libraries used:**
- React
- React Router DOM

**Structure & Practices:**
- Components are modular and separated by purpose: Contact list, contact details, message composition, and sent messages.
- State for sent messages is managed in the root App component.
- OTP is generated on the fly without storage or validation.
- Simple CSS used for styling.

**How to run locally:**
1. Clone the repository:
   ```bash
   git clone https://github.com/ani71ket/DataTaskers.git
   cd otp-messaging-app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the dev server:
   ```bash
   npm run dev
   ```

4. Open your browser at:
   ```
   http://localhost:5173
   ```

Make sure you have Node.js and npm installed before running the above steps.
